# Indexer Near Lake Framework



An example of an indexer written in Python using the [near-lake-framework](https://pypi.org/project/near-lake-framework/).

## Install

Install dependencies using [Poetry](https://python-poetry.org/):

```bash
poetry install
```

## Launch

```bash
poetry run python main.py --accounts aha_6.testnet --block-height 214692855
```
